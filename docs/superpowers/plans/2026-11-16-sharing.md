# Sharing and deep links Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A share button on event, person and host pages sends one https link with a preview card; the link opens the app when installed, otherwise a small web page.

**Architecture:** Two anon-callable preview functions in the database; one public Edge function `share-page` renders the preview HTML and the two well-known files; the app builds links from a `SHARE_BASE_URL` setting and resolves `/e/:code` and `/u/:username` with go_router. Nothing hard-codes a domain.

**Tech Stack:** Postgres/pgTAP, Deno (`deno test supabase/functions`), Flutter + Riverpod + go_router, `share_plus`.

**Spec:** `docs/superpowers/specs/2026-11-14-sharing-design.md` (with `docs/decisions/2026-11-10-fiuu-and-pending.md`). "Decided" are the owner's; "Defaults I chose" are used as written.

## Global Constraints

- Migrations are numbered after the latest on `main` (0125, which already holds host registration): `0126` and up.
- The domain is not bought: `SHARE_BASE_URL` is a setting, the placeholder is `https://share.example.invalid` (a reserved name that can never resolve); no code or test depends on a real domain.
- Links: `<SHARE_BASE_URL>/e/<share_code>` and `<SHARE_BASE_URL>/u/<username>`.
- `events.share_preview` returns nothing for `draft` and `cancelled`; works for private events; exposes no phone, payment or guest data. `identity.person_preview` returns only name, username, host flag, avatar, area (hosts).
- Private events: preview page works for anyone with the link and sends `noindex`; every page sends a short cache time.
- Store links, Android certificate fingerprint and iOS team id are placeholders read from the function's environment.
- Do not change `.github/workflows`; CI stays on Flutter 3.47.9. No PR.

## Review Focus

- A code with odd characters or very long input never breaks the page or injects HTML (Task 2 escapes every value).
- A cancelled or draft event answers 404 with the same page as a wrong code (Tasks 1 and 2).
- An empty `SHARE_BASE_URL` falls back to the `jom://` link instead of building a broken one (Task 3).
- A trailing slash and upper-case letters in a pasted link still resolve (Task 4).
- A signed-out visitor can open a shared link (Task 4).

**Interfaces:** `handleSharePage(req: Request, deps: SharePageDeps): Promise<Response>` with `SharePageDeps { baseUrl: string; eventPreview(code): Promise<EventPreview | null>; personPreview(username): Promise<PersonPreview | null>; androidSha256: string; iosTeamId: string; iosBundleId: string; androidPackage: string; playUrl: string; appStoreUrl: string }`. The path is matched by its tail (`/e/<code>`, `/u/<username>`, `/.well-known/assetlinks.json`, `/.well-known/apple-app-site-association`), so it works under `/functions/v1/share-page` and behind a domain.
